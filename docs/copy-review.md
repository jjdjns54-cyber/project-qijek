# DOODEE copy review

## Direction

DOODEE leads with the outcome a person or clinic wants, then explains the capability that enables it. Payment language describes access and flexibility; it does not manufacture urgency.

## Implemented changes

| Before | After | Why |
| --- | --- | --- |
| Free analysis | Included analysis | Frames the first view as a product value, not a giveaway. |
| Basic factor analysis | Core measurement overview | Removes downgrade language and explains the result. |
| Complete plan | Complete experience | Positions the paid tier as a fuller outcome. |
| Monthly membership | Monthly plan | Clear, familiar, and consistent with the billing model. |
| Start monthly plan | Get access to Complete | Names the result of the action. |
| Join the pilot / Request a demo | See it in action / Explore the workflow | Describes the next step without implying a false program or scarcity. |
| No new hardware | Use the devices you already have | Leads with the clinic benefit. |
| Unlock value | Reveal this measurement | Makes the locked action specific. |
| Estimated range | Estimated investment | Uses premium value language while keeping the range visible. |

## Claim guardrails

- Keep 85+ measurements, 2,000+ users, pricing and research references only where they are true and supportable.
- Do not add countdowns, limited spots, fake availability or comparative claims without evidence.
- Keep previews illustrative and non-diagnostic; do not imply a guaranteed treatment outcome.
- Keep “included analysis” distinct from the paid Complete experience so the offer remains understandable.
